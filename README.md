<h1 align="center">Discopilot</h1>
<p align="center">Your Copilot for Discord</p>

## Overview

Discopilot is a Discord bot that records voice channel conversations with built-in consent management. It streams individual per-user audio to a configurable backend, notifies new users when they join a recorded channel, and only records when all participants agree.

## Installation

```bash
git clone https://github.com/NicoGrassetto/buddy.git
cd buddy
npm install
```

Create a `.env` file with your Discord bot credentials, then start the bot:

```bash
npm start
```
